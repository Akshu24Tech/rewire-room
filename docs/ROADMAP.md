# Roadmap

## Phase 1: the debrief loop

Goal: one real moment in, one useful rep out, every quote verified.

- [x] Council protocol: safety screen, brief, two rounds, Evidence audit, debrief
- [x] Roster with all seven seats and build status
- [x] Seat agents for all seven seats
- [x] Quote checker (sessions against brains, brains against sources)
- [x] Ledger script (add, complete, stats)
- [x] Source fetcher and the `/newseat` builder with brain specs
- [ ] Build brains: Kukushkin, Huberman, Grant
- [ ] Build the Evidence brain (social anxiety exposure, implementation intentions, arousal reappraisal, personality change)
- [ ] First real debrief, saved as an example in `sessions/examples/`

Done when: three real debriefs produce reps the user actually did, and the quote checker passes on all of them.

## Phase 2: reps that compound

- [ ] `reps` mode: a weekly challenge ladder built from the ledger, easiest to hardest
- [ ] `check-in` mode: trends per situation type, reps dodged, what to change
- [ ] Ledger tags for situation types (class, work, social, online) and trend lines per type

Done when: the ledger shows discomfort dropping on at least one situation type over four weeks.

## Phase 3: the full council

- [ ] Build brains: Yousef, Greene, Galloway
- [ ] `prep` mode: before a hard moment
- [ ] `decide` mode: three-round council for personal decisions
- [ ] Seat for the user, built from their own journals and posts

## Later

- A small local page that charts the ledger
- Shareable debrief summaries with personal details stripped
