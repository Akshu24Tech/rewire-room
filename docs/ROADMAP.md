# Roadmap

## Phase 1: the debrief loop

Goal: one real moment in, one useful rep out, every quote verified.

- [x] Council protocol: safety screen, brief, two rounds, Evidence audit, debrief
- [x] Roster with all seven seats and build status
- [x] Seat agents for all seven seats
- [x] Quote checker (sessions against brains, brains against sources)
- [x] Ledger script (add, complete, stats)
- [x] Source fetcher and the `/newseat` builder with brain specs
- [x] Build brains: Kukushkin (138 quotes), Huberman (105), Grant (75)
- [x] Build the Evidence brain (39 quotes; exposure, implementation intentions, arousal reappraisal, reconsolidation, liking gap)
- [x] Worked debrief saved as an example in `sessions/examples/` (quote checker passes)

Done when: three real debriefs produce reps the user actually did, and the quote checker passes on all of them. (Framework and first worked example done; the three real ones are yours to run.)

## Phase 2: reps that compound

- [x] `reps` mode: a challenge ladder per situation type, built by a seat and calibrated to the ledger
- [x] `check-in` mode: trends per situation type, reps dodged, one focus for the week
- [x] Ledger tags for situation types and trend lines per type, plus a `--rung` field for ladders

Done when: the ledger shows discomfort dropping on at least one situation type over four weeks. (Modes built; the four weeks of data are yours to make.)

## Phase 3: the full council

- [ ] Build brains: Yousef, Greene, Galloway (run `/newseat` for each)
- [x] `prep` mode: before a hard moment
- [ ] `decide` mode: three-round council for personal decisions
- [ ] Seat for the user, built from their own journals and posts
